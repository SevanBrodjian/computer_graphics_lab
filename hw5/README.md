# HW5 Implicit Fairing

This program implements the implicit fairing smoothing approach on meshes loaded from obj files. To run, use:

```
./smooth [scene_description_file.txt] [xres] [yres] [h]
```

Press **`s`** to run the implicit fairing step using the provided time step `h`. Press **`q`** or **Esc** to quit.
